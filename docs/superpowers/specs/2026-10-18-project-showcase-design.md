# 首页项目展示设计

## 目标

通过 gh CLI 核实 Jaxon1216 的公开项目资料，为现有 Study Notes、Project Analyzer、GenBI 更新介绍，并新增 PomoTimer。为四个项目分别绘制预览图，完成浏览器验证后提交并推送。

## 设计选择

采用两列产品陈列卡片，640px 起一行两个，小手机单列。展示区域最大宽度 880px，卡片间距 16px，文字区内边距 16px，收紧纵向留白。用户已授权自由设计并推送，后续反馈要求缩小卡片，按此紧凑方案实施。

区域保持站点英文文案，以 Selected Projects 为主标题，补充简短导语和 GitHub 全部仓库入口。每张卡片由 16:9 横向预览、项目类别、名称、介绍、技术标签及文字操作组成。PomoTimer 排首位，随后为 Study Notes、Project Analyzer、GenBI。

图片是根据真实功能绘制的产品概念预览，不冒充真实截图。分别使用暖橙计时器、薄荷文档站、蓝色代码到学习文档、深蓝数据分析界面。图片只承载视觉，项目名称和操作保留为可访问的 HTML 文本。

## 实现边界

- 项目元数据继续维护在 lib/site-config.ts，保留现有 project id 与 analytics 语义。
- 使用本地 WebP 图片及 next/image，固定宽高比例和响应式 sizes，延迟加载。
- 继续沿用站点字体和明暗主题；提供键盘焦点样式并尊重 reduced motion。
- 只添加核实过的在线入口。PomoTimer 提供已核实的 Releases 下载入口，无公开演示的项目只提供源码。
- 不运行时请求 GitHub，不在卡片里加入会过期的 star 数或虚构状态。
- 不提交工作区既有的 .obsidian/、.temp/。

## 验收

四个项目各有准确文案、技术标签、独立预览图及有效仓库链接；Notes 有已验证的站点入口。桌面两列、移动单列、明暗主题均无溢出；所有图像成功加载，链接可键盘访问，analytics 属性保持。运行 lint、TypeScript 检查与生产构建，复核改动后提交并确认远程 SHA。
