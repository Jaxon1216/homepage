# MySQL 配图模板

图源随博客仓库维护。`model.json` 保存订单数据与分组，`generate.mjs` 保存可复用的 SVG 形状、连线及布局。无需新增依赖，不需要在线画板服务。

## 重新生成

在仓库根目录运行：

```bash
node diagrams/mysql/generate.mjs
```

## 数据与模板语法

当前订单模型与第一篇 SQL 示例一致：

```json
{
  "table": "orders",
  "lookupId": 6,
  "secondaryColumn": "user_id",
  "secondaryValue": 3,
  "overviewRootKeys": [1, 10, 20],
  "leafGroups": [[1, 2, 3], [4, 5, 6], [7, 8]],
  "directoryGroups": [[1, 2, 3, 4], [5, 6, 7, 8]],
  "orders": [
    {"id": 6, "user_id": 3, "amount": "70.00", "status": "paid"}
  ]
}
```

上面的 `orders` 只节选一行；完整模型保留八条订单。金额以字符串保存两位小数。

这是一套固定规模的教学模板。三个叶子页最多各显示三行；页目录图显示两个四条记录的普通组，以及首尾系统记录。更改数据值可复用现有布局；更改记录数、组数、查询目标或字段长度时，还需同步调整布局、范围文字和图注。生成器校验结构，不代替语义审阅。

可复用的绘图函数：

- `rect / text / line`：容器、可编辑文本、正交连线；文本统一 XML 转义。
- `directoryRecord`：n_owned、next、主键和行数据四格记录。
- `sentinel`：infimum / supremum 系统记录。
- `recordRow / leafPage`：主键叶子页的记录及命中高亮。
- `svg`：画布、标题、描述、箭头与统一配色。

所有图保留 `<text>`、`<title>` 与 `<desc>`。高亮使用文字、边框和箭头共同表达。

## 页目录参考图的复刻方式

依据用户提供的页目录截图重绘，保留：

- 数据页外框，左侧绿色目录槽列，右侧圆角记录分组；
- 粉色 n_owned、白色 next 指针、绿色主键和蓝色行数据；
- 红色虚线由目录槽指向组末记录，黑色实线由 next 字段指向下一条记录；
- infimum 最小记录，以及组末记录上的拥有计数。

原截图下方被裁切。本图使用本文的八条订单，补出 supremum 最大记录，使首尾关系完整，不声称恢复了原图不可见的内容。四个槽对应 infimum、记录 4、记录 8、supremum，拥有计数依次为 1、4、4、1；其他用户记录的 n_owned 为 0。普通组的计数范围是 4–8，首尾组允许例外。

图中的位置表达连接关系，不按实际页内字节偏移绘制。查找 id = 6 时，先由目录确定 4 < 6 ≤ 8，再从记录 4 沿 next 经过 5 找到 6。蓝色行数据部分省略了 user_id、amount、status 的具体值。

联合索引的参考图留在第二篇处理，不混入第一篇的主键树。

## 其他图的边界

- 架构图表达职责和调用关系；连接可以复用，执行器可以多次调用引擎接口，并不表示每条 SQL 必须重新建立连接。
- 三级总览图参考主键树截图的排布，根页 `overviewRootKeys` 用 1、10、20 表示范围下界；仅展开第一棵子树中的八条示例订单，10 与 20 所在分支省略，不表示示例 SQL 中另有这些行。叶子页展示四个业务列，省略内部字段与页外存储；实际叶子页双向连接，图中仅画向右链接。
- 主键树为演示分支，把八行分成三个叶子页；真实小表通常仍在同一个叶子页中。父层导航键是简化下界，省略最左项最小标志，不能当作父键始终等于子页当前最小值的保证。
- 叶子页逻辑相邻不意味着磁盘物理地址连续；叶子行省略其他列和可能的页外存储。
- 回表图假设优化器选择 user_id 二级索引。user_id = 3 对应主键 5、6、8；查询未过滤付款状态，因此订单 8 也匹配。只展开 id = 6 的一次回表，其余记录也需要取得所需列。主键值不是固定的磁盘地址。

## 检查

重新生成后，在浏览器或 SVG 查看器中检查中文、连线、边界与图注。改动数据后手走查询路径，并核对 SQL 示例；页目录图特别检查槽指向组末记录、next 指针方向及 n_owned 计数。

可使用项目已有的 sharp 渲染预览；渲染工具只用于检查，不是博客运行时的新依赖。文章通过普通 Markdown 图片语法引用这些 SVG，沿用已有图片预览功能。
