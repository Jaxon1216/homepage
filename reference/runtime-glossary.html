后端运行模型

从代码到请求的一组基本概念。

代码、进程、线程

代码：函数、语句等组成的程序。进程：运行中的程序实例，具有独立的进程地址空间。线程：进程内被操作系统调度的执行单元；同一进程中的线程共享进程地址空间，执行各自当前调用路径的指令。

并发、线程池、连接池

并发：多个任务在一段时间内都有进展，不要求同一时刻各自运行。并行：多个任务在同一时刻执行。线程池：复用线程来执行工作。连接池：管理到数据库等服务的连接，以供操作复用。两个池管理的不是同一种资源。

Node 常见模型

一个进程的默认主线程执行普通 JS 和事件循环回调；其他运行时线程可执行某些工作。非阻塞网络 I/O 可借助操作系统，完成后再安排后续 JS；CPU 密集的同步 JS 可能阻塞主线程。参见 Node 官方指南。
